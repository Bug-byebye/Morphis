# 场景迁移说明

## 问题分析

当前主场景位于 `Assets/StarterAssets/ThirdPersonController/Scenes/Playground.unity`，这对于计划上线的游戏来说**不合适**，原因如下：

1. **第三方资源包目录**：`StarterAssets` 是第三方资源包，不应该放置项目主场景
2. **依赖风险**：如果资源包更新或删除，主场景可能丢失
3. **不符合大厂标准**：专业项目的主场景应放在项目自有目录

## 大厂标准

按照大厂游戏项目的标准，主场景应该：

- **位置**：`Assets/Game/Scenes/` 或 `Assets/Scenes/`
- **命名**：清晰明确，如 `MainScene.unity`、`GameplayScene.unity`
- **独立性**：不应依赖第三方资源包的目录结构

## 推荐目录结构

```
Assets/
├── Game/                    # 游戏核心内容
│   └── Scenes/             # 游戏场景
│       ├── MainScene.unity # 主游戏场景
│       └── BootScene.unity # 启动场景（可选）
├── Scenes/                 # 或使用此目录
│   └── MainScene.unity
└── StarterAssets/          # 第三方资源包（只读参考）
    └── ...                 # 不应在此放置主场景
```

## 迁移步骤

### 方法一：使用迁移工具（推荐）

1. 在 Unity 编辑器中，点击菜单：`Tools > Morphis > 场景迁移 > 迁移主场景到标准目录`
2. 工具会自动：
   - 复制场景文件到 `Assets/Game/Scenes/MainScene.unity`
   - 更新 Build Settings
   - 可选：自动更新代码中的场景名称引用

3. 验证迁移：`Tools > Morphis > 场景迁移 > 验证场景迁移状态`

### 方法二：手动迁移

1. **复制场景文件**
   - 在 Project 窗口中找到 `Assets/StarterAssets/ThirdPersonController/Scenes/Playground.unity`
   - 复制到 `Assets/Game/Scenes/MainScene.unity`
   - 如果 `Game/Scenes` 目录不存在，先创建

2. **更新 Build Settings**
   - `File > Build Settings`
   - 移除旧的 `Playground.unity`
   - 添加新的 `MainScene.unity`

3. **更新代码引用**
   - 搜索所有包含 `"Playground"` 的脚本
   - 替换为 `"MainScene"`
   - 主要文件：
     - `Assets/Scripts/AppFlow/BootFlowManager.cs`
     - `Assets/Scripts/ObjectInteractionBootstrap.cs`
     - `Assets/Scripts/ModelPlacement/ModelLibraryBootstrap.cs`
     - `Assets/Editor/AppFlowSetup.cs`

## 注意事项

1. **备份**：迁移前建议备份项目
2. **测试**：迁移后务必测试场景加载是否正常
3. **版本控制**：确保 `.meta` 文件也被正确迁移
4. **依赖检查**：确认场景中的资源引用仍然有效

## 迁移后的代码更新

以下文件需要更新场景名称：

- `BootFlowManager.cs`: `mainSceneName = "MainScene"`
- `ObjectInteractionBootstrap.cs`: `TargetSceneName = "MainScene"`
- `ModelLibraryBootstrap.cs`: `TargetSceneName = "MainScene"`
- `AppFlowSetup.cs`: 更新场景路径常量

## 验证清单

- [ ] Build Settings 中包含新场景
- [ ] 代码中的场景名称引用已更新
- [ ] 场景可以正常加载
- [ ] 所有功能正常工作
